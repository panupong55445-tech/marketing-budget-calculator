# เครื่องคำนวณงบการตลาดออนไลน์รายเดือน

ใช้เทียบใบเสนอราคาที่รวมงานคนละแบบ โดยแยกค่าบริการทีม งบที่จ่ายให้แพลตฟอร์มโฆษณา และค่าใช้จ่ายอื่น เช่น ค่าเดินทางหรือค่าอุปกรณ์

[เปิดเครื่องคำนวณ](https://panupong55445-tech.github.io/marketing-budget-calculator/)

## ตัวอย่างคำนวณ

| รายการ | บาทต่อเดือน |
| --- | ---: |
| ค่าบริการทีม | 25,000 |
| งบโฆษณา | 12,000 |
| ค่าใช้จ่ายอื่น | 3,000 |
| **รวม** | **40,000** |

ถ้าตั้งเป้า 20 คำขอที่ตรงโจทย์ ให้นำ 40,000 ÷ 20 จะได้ **2,000 บาทต่อคำขอตามเป้า** เมื่อสิ้นเดือนให้ใช้จำนวนคำขอจริงและค่าใช้จ่ายจริงแทนตัวเลขตั้งต้น ตัวอย่างนี้ใช้เปรียบเทียบวิธีคิดงบ

เครื่องมือทำงานในเบราว์เซอร์ เปิดไฟล์ index.html ได้โดยตรง ข้อมูลตัวเลขที่กรอกใช้คำนวณในหน้าเว็บ

จัดทำโดย [ONE SOCIAL](https://one-social.media/) สำหรับเจ้าของธุรกิจที่กำลังเทียบขอบเขตและงบการตลาดรายเดือน
